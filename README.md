# LJT-Homepage

Personal homepage of Junteng Liu, a first-year PhD candidate at the HKUST NLP Group (Hong Kong University of Science and Technology), built with the [Academic Pages](https://github.com/academicpages/academicpages.github.io) Jekyll template (forked and renamed for GitHub Pages hosting).

## Site content

- **Home / About** (`/`): personal introduction, research interests, academic background, research experience, honors, skills, publications, and contact information.
- **Publications** (`/publications/`): list of publications, grouped by category.
- **CV** (`/cv/`): curriculum vitae covering education, research experience, honors, skills, and publications.

Individual publications are stored as Markdown files in `_publications/`; site configuration is in `_config.yml`.
